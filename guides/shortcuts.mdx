On a Mac, every **Ctrl** shortcut below also works with **Cmd**. Press **Ctrl+/** in the app for the full list.

## Search every action

Press **Ctrl+K** to open the command palette. Type part of a name to find any action: play, pause, reset, share, crash or fix a part, add a component, open an example, a challenge or an incident, or look up a glossary term. Press Enter to run it.

## Control the run

| Key | What it does |
| --- | --- |
| Space | Play or pause |
| S | Step one tick |
| [ and ] | Play slower or faster |
| F | Open Can you break it? |

The speed button in the top bar cycles through 0.5x, 1x, 2x and 4x. Speed only changes how fast the run plays on your screen. Checks, replays and links always run at their own fixed pace, so speed never changes a result.

## Build faster

- **Ctrl+C**, **Ctrl+X** and **Ctrl+V** copy, cut and paste a selection. Paste lands at the pointer, and pasted parts never clash with ones already on the canvas, so you can paste into another design too.
- **Ctrl+D** duplicates the selection, and **Alt+drag** drags out a copy.
- **L** connects the selected component: arrows pick the target, Enter connects.
- **Ctrl+Z** undoes and **Ctrl+Shift+Z** or **Ctrl+Y** redoes. Faults you inject are undoable too.
- Number fields in the inspector have **-** and **+** buttons beside them, so you can step a value without typing.

## Context menus

Right-click a component, a connection or the empty canvas, or press and hold on a touch screen.

- **A component:** Inspect, Duplicate, Copy, Connect to, Crash, Slow down, Fix and Delete.
- **A connection:** Inspect, Cut connection or Restore connection, add or remove packet loss, and Delete connection.
- **The canvas:** Paste here, Add component here and Fit diagram.

## Pin this run

To compare before and after a change:

1. Let the run settle, then press **Pin this run** at the top of the charts strip.
2. Change the design.
3. Read the strip. It shows the three top-bar figures as then and now, and the charts draw the pinned run as a dotted line on the same axes.

## Presenting mode

Press **P**, or pick **Start presenting** from the menu, to show the canvas and the live numbers large for a room. While presenting, select a part or Tab to one, then:

- **X** crashes it,
- **W** slows it,
- **R** fixes it.

These three keys only work while presenting. Press **P** again, or **Stop presenting**, to leave. Presenting is never saved into a link or a file, so a reload always comes back to the normal app.

## Empty canvas

An empty canvas offers three ways in: **Start with one service**, **Browse examples** and **Try a challenge**. Or drag a client, a service and a database in from the left.

## Links that open a view

The address bar says what is on screen, so you can copy it to open the same thing.

- `?example=` and an example id opens that example, for example `https://breakscale.tech/?example=retry-storm`. The id is the last part of each example page's address in these docs.
- `?challenge=` and a challenge id opens that brief, for example `https://breakscale.tech/?challenge=hold-the-line`.

A link from **Share** is different: it carries your own design, and optionally the exact run.
